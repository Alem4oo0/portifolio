# Portfólio — Carlos Henrique Cintra

Site estático preparado para **GitHub Pages**, usando HTML5, CSS3 e JavaScript puro.

## Arquivos principais

- `index.html` — estrutura, conteúdo e metadados do site.
- `styles.css` — identidade visual, componentes e layout responsivo.
- `script.js` — menu mobile, filtros, lightbox e calculadora de orçamento.
- Imagens `.webp`, `.svg` — fotografias, projetos, padrões de azulejo e favicon. **Neste pacote, os arquivos de imagem ficam na mesma pasta que o `index.html`, para combinar com a estrutura atual do repositório.**
- `portfolio-em-pdf.pdf` — apresentação para download.
- `.nojekyll` — evita processamento desnecessário pelo Jekyll.
- `robots.txt` e `sitemap.xml` — orientação básica para mecanismos de busca.
- `404.html` — página amigável para endereços não encontrados.

## Atualizar o repositório atual

O repositório `Alem4oo0/portifolioo` atualmente mantém os arquivos de imagem na raiz. Por isso, esta versão usa caminhos relativos como `carlos-retrato-hero.webp` em vez de `assets/carlos-retrato-hero.webp`.

1. Extraia este ZIP.
2. No GitHub, abra o repositório `Alem4oo0/portifolioo`.
3. Use **Add file → Upload files**.
4. Envie o conteúdo desta pasta para a raiz do repositório, substituindo `index.html`, `styles.css`, `script.js`, `README.md`, `robots.txt` e os arquivos de imagem com o mesmo nome.
5. Faça o commit na branch `main`.
6. Mantenha o GitHub Pages configurado para publicar a branch `main`, pasta `/(root)`.

**Importante:** não envie o ZIP fechado para a raiz. Extraia primeiro e envie os arquivos internos. Não crie uma pasta extra envolvendo o site.
