PACOTE DE ATUALIZAÇÃO PARA O REPOSITÓRIO JÁ PUBLICADO

Este pacote corresponde ao layout atual do repositório Alem4oo0/portifolioo. Os arquivos de imagem ficam na mesma pasta que o index.html, porque o repositório atual mantém as imagens na raiz.

1. Extraia este ZIP.
2. Envie o conteúdo da pasta extraída para a raiz do repositório no GitHub.
3. Substitua os arquivos com o mesmo nome e faça o commit na branch main.
4. Em Settings > Pages, mantenha main e /(root).

Não envie o ZIP fechado e não coloque os arquivos dentro de uma pasta adicional.
Veja README.md para detalhes.
